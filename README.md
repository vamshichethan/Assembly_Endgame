## 🛠️ Assembly Endgame

A fun and interactive word-guessing game built as part of the **Scrimba Frontend Developer Path**. The goal is to save the programming language from being “assembled” one letter at a time — similar to Hangman, but with a developer twist!

---

## 🧩 Features
- 🎮 Interactive letter guessing system  
- 🔤 Random word generation  
- 💻 Programming-themed UI  
- 🎉 Win and lose states with visual feedback  
- ♿ Accessible buttons with ARIA labels  
- 📱 Responsive design

---

## 🛠️ Built With
- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **React**
- **Vite**
